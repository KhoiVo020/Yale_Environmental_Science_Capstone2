# Capstone Prompt 2 discussion draft

Repository: [Yale Environmental Science Capstone](https://github.com/KhoiVo020/Yale_Environmental_Science_Capstone2)

My project investigates land-cover change and population growth in Orange and Riverside Counties, California, using 2000, 2010, and 2020 observations. For this stage, I used `filter()` to select the counties and total-population records from the Census data, converted population counts from text to numbers, preserved and joined county identifiers, and checked for missing or duplicate county-year observations. I then used `mutate()`, `group_by()`, and `summarise()` to calculate population changes within each county; these steps produced a consistent table for later comparison with land-cover areas. Next, I will compare matched Annual NLCD cells and report both acres converted to development and the percentage of each starting land-cover category converted, so a category with a large initial area does not automatically appear to be the most affected.
